# SEA Change Intelligence Dashboard

## Work style
- Work token-efficiently.
- Inspect only task-relevant files.
- Make minimal targeted edits.
- Do not rewrite full files unless necessary.
- Do not paste full file contents unless asked.
- Keep explanations short.
- Reuse existing architecture.

## Data rules
- Never invent data.
- Never label sample data as actual.
- Never label forecast as official actual.
- Never call annual official data “live.”
- 2026 data must be partial/preliminary unless full-year official data exists.
- Every data value must include source, source_url, value_type, data_quality, confidence, and limitation_note.

## Source priority
1. National official actual
2. Central bank actual
3. Ministry/customs/agency actual
4. Regional official actual
5. World Bank / IMF / ADB / OECD actual or forecast
6. GDELT/news as signal only

## Project scope
Countries:
Thailand, Vietnam, Myanmar, Cambodia, Laos, Malaysia, Singapore, Indonesia, Philippines, Brunei, Timor-Leste, China, United States, Japan, India, South Korea, Australia, European Union.

Sectors:
macro economy, inflation, labor, trade, investment, finance, fiscal, tourism, industry, agriculture, energy, technology, infrastructure, environment, politics, security, social indicators.

## Required workflow
For every task:
1. Inspect only relevant files.
2. Give a short plan.
3. Make minimal edits.
4. Run or provide tests.
5. Summarize changed files and result.
